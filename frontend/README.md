# 3D Printer Predictive Maintenance Dashboard

A React-based dashboard for monitoring 3D printer health, detecting anomalies, and providing maintenance recommendations.

## Features

- Real-time health monitoring
- Vibration analysis
- Anomaly detection
- Maintenance recommendations
- Digital twin visualization

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set backend URL:
   ```bash
   # Create .env file
   VITE_API_BASE_URL=http://localhost:5000/api
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
